C++ Console Application

ReadyQuest – Household Emergency Readiness Coach

ReadyQuest is a C++ console application designed to help people learn about household emergency preparedness. The application provides educational lessons, interactive emergency scenarios, household preparedness tracking, and randomized emergency events. The goal of this project is to make emergency preparedness more interesting by allowing users to learn, make decisions, earn points, and track their progress.

Key Features

  • Emergency Lessons: Provides information about different emergencies and safety procedures.
  • Interactive Scenarios: Allows users to make decisions during simulated emergency situations.
  • Progress Tracking: Keeps track of completed lessons, scenarios, and earned points.

One challenge I faced was getting my C++ classes to work together. I solved it by checking my code, fixing errors, and testing the program. I learned how to debug problems and how important it is to understand how classes work together.
